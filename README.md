# 연구 주제

## 연방 양형가이드라인의 실제 형벌 유형 및 선고기간 예측력과 추가 사건정보의 증분 예측가치 분석

본 연구는 **연방 양형가이드라인 정보가 실제 선고결과를 어느 정도 예측할 수 있는지**, 그리고 **가이드라인 외의 사건정보를 추가했을 때 그 예측력이 얼마나 개선되는지** 분석한다.

실제 양형결과는 형벌의 **유형**과 **기간**이라는 서로 다른 두 측면을 가지므로, 이를 두 개의 분석으로 나누어 살펴본다.

1. 실제 선고가 어떤 형벌 유형에 해당하는지 예측하는 **형벌 유형 분류**
2. 실제로 기간형이 선고된 사건에서 선고기간을 예측하는 **선고기간 회귀**

두 분석에서 모두 가이드라인 정보만을 이용한 모델을 기준으로 설정하고, 추가 사건정보를 포함했을 때 예측성능이 얼마나 증가하는지를 비교한다.

---

# 연구 대상

연구 대상은 USSC Individual Datafile의 FY2021–FY2025 사건 중 **가이드라인 정보를 정상적으로 확인할 수 있는 사건**으로 한정한다.

따라서

* `SOURCES == 1`

인 사건만을 분석한다.

---

# 반응변수

## 1. 형벌 유형

실제 선고결과를 다음 네 가지 유형으로 구분한다.

* **0 = 무기징역**
* **1 = 기간형**
* **2 = 보호관찰 Only**
* **3 = Fine Only**

여기서 **기간형**은 징역형뿐 아니라 실제 기간으로 측정할 수 있는 자유제한이 존재하는 선고를 포함한다.

따라서 다음과 같은 경우가 기간형에 포함된다.

* Prison Only
* Prison + Alternative Confinement
* Probation + Alternative Confinement

반면 대체구금 없이 보호관찰만 부과된 사건은 **Probation Only**, 징역이나 보호관찰 없이 벌금만 부과된 사건은 **Fine Only**로 구분한다.

---

## 2. 기간형의 선고기간

실제로 **기간형이 선고된 사건**에서는 실제 선고기간을 별도의 연속형 반응변수로 분석한다.

반응변수는

* `SENSPLT0`

을 사용한다.

`SENSPLT0`은 징역과 대체구금 등 실제 기간으로 측정할 수 있는 자유제한을 종합한 USSC 연구변수이므로, 본 연구에서는 이를 **실제 선고기간 또는 자유제한 기간**으로 사용한다.

---

# 분석 구조

본 연구는 두 개의 분석을 병렬적으로 수행한다.

## Track A. 형벌 유형

전체 사건을 대상으로 실제 선고가

* 무기징역
* 기간형
* Probation Only
* Fine Only

중 어느 유형에 해당하는지 예측한다.

먼저 가이드라인 정보만을 이용한 Baseline 모델을 구축하고, 이후 추가 사건정보를 포함하여 **네 가지 형벌 유형의 예측성능이 얼마나 개선되는지** 평가한다.

주요 평가 기준은 **Macro F1과 Class별 성능**이다.

---

## Track B. 기간형 선고기간

실제로 기간형이 선고된 사건만을 대상으로 실제 선고기간을 예측한다.

마찬가지로 가이드라인 정보만을 이용한 Baseline 모델과 추가 사건정보를 포함한 모델을 비교하여 **선고기간 예측력이 얼마나 개선되는지** 평가한다.

주요 평가 기준은

* MAE
* RMSE
* R²

이다.

---

# 핵심 비교

두 분석의 핵심은 동일하다.

> **Guideline-only Model**
> vs.
> **Guideline + Additional Case Information Model**

### 형벌 유형

추가 사건정보가

* Macro F1을 높이는가?
* 각 형벌 유형의 F1과 Recall을 개선하는가?
* 특정 형벌 유형 사이의 오분류를 줄이는가?

를 확인한다.

### 선고기간

추가 사건정보가

* MAE를 감소시키는가?
* RMSE를 감소시키는가?
* R²를 증가시키는가?

를 확인한다.

---

# 연구 목적

본 연구의 목적은 새로운 양형기준을 직접 제안하는 것이 아니다.

핵심은

> **현행 연방 양형가이드라인이 실제 형벌의 유형과 기간에 대해 어느 정도의 예측정보를 가지고 있으며, 가이드라인 외의 사건정보가 그 이상의 추가적인 예측정보를 제공하는지를 확인하는 것**

이다.

따라서 추가 사건정보의 가치는 특정 변수와 선고결과 사이의 단순한 상관관계가 아니라 **가이드라인 정보만을 사용한 모델에 비해 실제 예측성능을 얼마나 개선하는지**를 기준으로 평가한다.

형벌 유형과 선고기간은 별개의 분석으로 다루며, **형벌 유형 분류모델의 예측결과를 선고기간 회귀모델로 전달하지 않는다.**

기간형 선고기간 분석에서는 실제로 기간형이 관찰된 사건만을 사용한다.

이를 통해

* 가이드라인이 **어떤 형벌이 선택되는지** 얼마나 설명하는지
* 기간형이 선택된 경우 **얼마나 긴 기간이 선고되는지** 얼마나 설명하는지
* 추가 사건정보가 두 측면의 예측력을 각각 얼마나 개선하는지

를 평가한다.

# 사용 데이터
구분	연도	목적
Train	-> FY2021–FY2023	군집화, 오차 분석, Baseline 및 확장모델 학습
Validation -> FY2024	모델 선택, 추가 피처 및 하이퍼파라미터 검증
Test	-> FY2025	최종 성능 및 시간적 일반화 성능 평가

# 프로젝트 과정
  1. 분석 대상 및 설명/반응변수 정의
     - 형벌 유형 분류기 A - 설명변수 = 'GLMIN','GLMAX'
     - 형벌 유형 분류기 B - 설명변수 = 'GLMIN','GLMAX','ZONE'
     - 분류기 반응변수('Class') = 0 - 무기징역/사형 // 1 - 실제 자유 제한 기간이 있는 경우 // 2 - 보호관찰만 // 3-벌금형
    
     - 설명변수가 1일 경우 - 실제 자유 제한 기간을 예측하는 baseline 회귀모델로 예측
     - baseline 회귀모델 - 설명변수 = 'GLMIN','GLMAX', ... 반응변수 = 실제 자유 제한 기간

     - 군집화 피처 = 'PRESENT','NEWCNVTN','DISTRICT','CITIZEN','AGE','NEWEDUC' ( 1차 )
    
     # 데이터 전처리
       - 'Class' 열 생성
       - 'GLMIN','GLMAX'에 특수값 존재 -> 특수값인 경우를 nan처리한 'GLMIN_MONTH','GLMAX_MONTH' 생성 ( 나중에 파이프라인으로 nan 대체 -> 미리 대체하면 데이터 누수 )
       - 'GLMIN_LIFE',"GLMAX_LIFE'도 생성해서, 9996일 때 1인 범주형 변수 만들기.
       - 'GLMIN_ZERO'도 만들어서, GLMIN==0일 때 보호관찰을 허용한다는 점을 이용하기.
         
  2. 모델 구축
      - 클래스의 수가 0(349), 1(165461), 2(9712), 3(185)로 클래스 불균형이 심한 상황이다. -> StratifiedKFold(CV)로 교차 검증할 때 클래스의 비율을 유지한다.
      - 모델 평가 기준
        - 주 평가 기준 = Marco F1
