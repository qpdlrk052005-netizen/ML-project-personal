# 연구 주제
연방 양형가이드라인은 실제 양형을 얼마나 잘 설명하며, 어떤 사건 특성을 추가하면 미래 양형 및 가이드라인 이탈 예측을 개선할 수 있는가?

# 연구 목적
지금 가이드라인이 실제 양형을 설명하기에 충분한지 확인하고, 부족하다면 어떤 사건에서 왜 부족한지 찾아본 뒤, 그 정보를 추가하면 실제로 더 잘 예측할 수 있는지 확인하는 연구이다.

# 연구 순서
1.	현재 가이드라인이 실제 양형과 얼마나 잘 맞는가?
2.	선고 전에 알 수 있는 사건 정보들을 바탕으로 비슷한 사건끼리 묶는다.(비지도)
3.	가이드라인이 잘 맞지 않는 사건 유형을 찾는다.
4.	해당 사건 유형을 다시 보면서, 어떤 변수들이 유형을 특징짓는지 찾는다.
5.	발견한 변수들을 가이드라인 정보에 하나씩 논리적으로 추가하면서 실제 형량 및 이탈 예측 성능이 개선되는 지 확인한다.(지도)
6.	미래 사건에서도 성능 개선이 유지되는 지 검토한다
7.	어떤 정보가 기존 가이드라인의 예측 한계를 보완할 가능성이 있는 지 결론 낸다.

# 사용 데이터
Train- 21~23년도
validation - 24년도
test - 25년도

# 프로젝트 설계
setup - 21~25년도의 열 추출 -> 공통된 열만 사용한다.(연구의 통일성을 위함)

1. 현재 가이드라인이 실제 양형과 얼마나 잘 맞는가?
   - 21~25년도의 예상 양형 구간에 실제 형이 포함되어 있는 지?
   - GLMIN,GLMAX는 최종적으로 내려진 최종 가이드라인의 범위. SENTTCAP은 실제 양형 
   - 다수의 결측치 발견 -> SENTTCAP의 결측치는 보호관찰 일 때임. -> '실제 징역'을 받은 사람들만 대상으로 조사 -> 결과를 이용한 표본 선택 문제 발생
   - 보호관찰일 때도 다뤄 보자. -> SENSCAP 변수 사용
     
| 실제 선고             | `SENSPCAP` |
| ----------------- |  ---------: |
| 징역 24개월           |         24 |
| 징역 4개월 + 가택구금 4개월 |          8 |
| 보호관찰만 선고          |      **0** |
| 종신형               |    **470** |
| 470개월 초과 유기징역     | **469.99** |
| 진짜 결측/판정불가/해당없음   |        NaN |

   - 예측 보호관찰 -> 양형 보호관찰인 경우는 관찰되지 않음. -> 그렇다면 GLMIN이 0일 때 보호관찰도 가능하다.. 임을 포함하는가? -> 맞다. -> 그렇다면 GLMIN<=SENSPCAP<=GLMAX면 문제 없을 것.
