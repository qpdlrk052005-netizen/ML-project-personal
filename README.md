# 연구 주제

**연방 양형가이드라인은 실제 선고형량을 어느 정도 설명하는가? 그 설명력이 특히 낮은 사건 유형은 무엇이며, 가이드라인 외의 사건 특성을 추가하면 실제 선고형량에 대한 설명·예측력이 얼마나 개선되는가?**

# 연구 목적

본 연구는 미국 연방 양형가이드라인이 제공하는 최종 권고 형량 정보를 기준점으로 삼아 실제 선고형량에 대한 설명력과 예측력을 평가하는 것을 목적으로 한다.

먼저 `GLMIN`, `GLMAX` 등 사건별 공식 가이드라인 정보를 이용하여 실제 선고형량을 예측하는 **Guideline-only baseline model**을 구축한다. 이를 통해 현행 가이드라인 정보만을 이용했을 때 실제 선고형량의 변동을 어느 정도 설명할 수 있는지 평가한다.

다음으로 실제 선고형이 결정되기 전에 관찰 가능한 사건 및 피고인 특성을 이용하여 유사한 사건들을 군집화하고, 각 군집에서 baseline model의 예측오차가 어떻게 달라지는지 비교한다. 이를 통해 특정 유형의 사건에서 가이드라인의 실제 선고형량 설명력이 체계적으로 낮아지는지를 확인한다.

이후 baseline model의 예측잔차를 이용하여 설명력이 낮은 군집에서 어떤 사건 특성이 큰 예측오차와 관련되어 있는지를 분석한다. 단순히 가이드라인 범위 안팎을 구분하는 것이 아니라,

[
e_i=Y_i-\hat{Y}_i^{(G)}
]

를 정의하여, 가이드라인 정보로 설명되지 않는 실제 선고형량의 변동이 어떤 사건 특성과 관련되는지를 분석한다.

그 결과 발견된 추가 특성을 기존 가이드라인 정보에 단계적으로 추가하여 **Guideline + Additional Features model**을 구축하고, baseline model보다 실제 선고형량 예측 성능이 개선되는지를 평가한다.

마지막으로 미래 연도의 데이터를 이용한 시간적 외부검증을 통해 이러한 성능 개선이 새로운 사건에서도 유지되는지 확인한다. 이를 바탕으로 특정 사건 정보가 현행 가이드라인의 실제 양형 설명 한계를 보완하는 **추가적인 예측정보**를 제공하는지 평가한다.

본 연구의 목적은 새로운 법적 양형가이드라인을 제시하는 것이 아니라, **현행 가이드라인 정보만으로 설명되지 않는 실제 양형의 변동을 규명하고 이를 추가적으로 설명할 수 있는 사건 정보를 탐색하는 것**이다.

# 연구 순서

1. **분석대상과 변수 정의**

   * 실제 선고형량을 종속변수로 정의한다.
   * `GLMIN`, `GLMAX` 등 공식 가이드라인 정보를 baseline predictor로 정의한다.
   * 실제 선고 이후에 생성되는 정보나 이탈 사유 등 타깃 누수가 발생할 수 있는 변수는 예측변수에서 제외한다.

2. **Guideline-only Baseline Model 구축**

   * 현행 가이드라인 정보만을 이용하여 실제 선고형량을 예측한다.
   * MAE, RMSE, (R^2) 등을 이용하여 전체 사건에서의 설명력과 예측성능을 측정한다.
   * 이를 이후 모든 확장모델의 비교 기준으로 사용한다.

3. **사건 특성 기반 군집화**

   * 실제 선고형이 결정되기 전에 관찰 가능한 사건 특성을 이용하여 유사한 사건들을 비지도학습으로 군집화한다.
   * 종속변수인 실제 선고형량이나 baseline model의 오차를 군집 생성 자체에 사용하지 않는다.

4. **군집별 Baseline 성능 평가**

   * 각 군집에서 Guideline-only baseline model의 MAE, RMSE, (R^2) 등을 계산한다.
   * 전체 평균에 비해 가이드라인 정보의 설명력이 현저히 낮은 사건 유형을 식별한다.

5. **예측오차 진단**

   * 각 사건에 대해 baseline model의 잔차

[
e_i=Y_i-\hat{Y}_i^{(G)}
]

와 절대오차

[
|e_i|
]

를 계산한다.

* 설명력이 낮은 군집에서 어떤 사건 특성이 큰 (|e_i|)와 관련되는지 분석한다.
* 필요할 경우 오차의 크기뿐 아니라 양의 잔차와 음의 잔차를 구분하여 실제 선고형이 baseline prediction보다 체계적으로 높거나 낮은 사건 특성이 존재하는지도 확인한다.

6. **추가 피처의 증분 예측가치 평가**

   * 진단 단계에서 발견된 후보 특성을 기존 가이드라인 정보에 하나씩 또는 단계적으로 추가한다.

[
M_G:Y=f(G)
]

[
M_{G+X}:Y=f(G,X)
]

* 동일한 검증표본에서 두 모델의 MAE, RMSE, (R^2) 등을 비교한다.
* 단순히 추가 변수가 통계적으로 유의한지가 아니라 **out-of-sample prediction error를 실제로 감소시키는지**를 핵심 기준으로 삼는다.

7. **군집별 개선효과 분석**

   * 추가 특성에 의한 성능 개선이 전체 표본에서만 나타나는지, 특정 군집에서 집중적으로 나타나는지를 평가한다.
   * 특히 baseline 설명력이 낮았던 군집에서 추가 특성이 오차를 유의하게 줄이는지를 확인한다.

8. **시간적 외부검증**

   * 이전 연도의 자료로 모델을 학습하고 미래 연도의 사건을 이용하여 성능을 평가한다.
   * 미래 자료에서도 Guideline + Additional Features model이 Guideline-only model보다 안정적으로 우수한지 검증한다.

9. **경험적 선고분포 분석**

   * 필요한 경우 분위수 회귀 등을 이용하여

[
Q_{\tau}(Y|G,X)
]

를 추정한다.

* 기존 `GLMIN–GLMAX`와 추가 사건 특성을 조건화한 경험적 선고분포를 비교한다.
* 이를 통해 특정 사건 유형에서 공식 guideline range 주변의 실제 선고분포가 어떻게 달라지는지를 보조적으로 분석한다.

10. **결론**

* 현행 가이드라인 정보가 실제 선고형량을 어느 정도 설명하는지 정리한다.
* 설명력이 특히 낮은 사건 유형을 제시한다.
* 어떤 추가 사건 특성이 가이드라인만으로 설명되지 않는 변동을 반복적으로 설명하는지 확인한다.
* 이러한 추가정보가 미래 사건에서도 예측성능을 개선하는 경우, 현행 가이드라인의 **경험적 예측 한계를 보완할 가능성이 있는 정보**로 해석한다.

# 연구의 핵심 비교

본 연구에서 가장 중요한 비교는 다음 두 모델이다.

### Model G: Guideline-only model

[
\hat{Y}^{(G)}=f(G)
]

여기서 (G)는 `GLMIN`, `GLMAX` 등 현행 양형가이드라인이 제공하는 정보이다.

### Model G+X: Extended model

[
\hat{Y}^{(G+X)}=f(G,X)
]

여기서 (X)는 가이드라인 외의 추가 사건 특성이다.

따라서 핵심 연구대상은

[
\Delta Error
============

Error_{G+X}-Error_G
]

이다.

예를 들어,

[
MAE_G=15.2
]

이고

[
MAE_{G+X}=12.7
]

이라면,

[
\Delta MAE=-2.5
]

이므로 추가 특성이 평균적으로 실제 선고형량 예측오차를 2.5개월 감소시킨 것으로 평가한다.

이를 전체 사건뿐만 아니라 각 군집 및 미래 연도에서도 반복하여 평가한다.

# 연구에서 하지 않는 것

본 연구에서는 `SENTRNGE`를 사용하여 공식적인 가이드라인 내·외 여부를 복원하거나 예측하지 않는다.

또한 직접 계산한 `GLMIN ≤ 실제 형량 ≤ GLMAX` 여부를 USSC의 공식적인 가이드라인 이탈 판정으로 간주하지 않는다.

연구의 대상은 **가이드라인 이탈 여부 자체가 아니라, 현행 가이드라인 정보가 실제 선고형량을 얼마나 설명하는가**이다.

따라서 추가 특성으로 성능이 개선되더라도 이를 곧바로

> “해당 변수를 양형가이드라인에 추가해야 한다.”

라고 해석하지 않는다.

본 연구가 검증하는 것은

> **“해당 정보가 현행 가이드라인 정보에 포함된 것 이상의 추가적인 실제 양형 예측정보를 가지고 있는가?”**

이다.

즉 최종 결과는 **법적·규범적 가이드라인의 대체안이 아니라 현행 가이드라인의 경험적 설명·예측 한계에 대한 진단**으로 해석한다.

 2. 가이드라인에 이미 반영되어있는 피처를 제외하고, 다른 연구로 실제 양형에 영향을 줄 수 있음이 밝혀진 피처들을 이용해 군집화한다.
