# 연구 주제

## 연방 양형가이드라인의 실제 형벌 유형 및 선고기간 설명력과 추가 사건정보의 증분 예측가치 분석

**연방 양형가이드라인은 실제 형벌 유형과 선고기간을 어느 정도 설명하는가?
그 설명력이 특히 낮은 사건 유형은 무엇이며, 가이드라인 외의 사건 특성을 추가하면 실제 양형에 대한 예측력을 얼마나 개선할 수 있는가?**

---

# 연구 대상

연구 대상은 **연방 양형가이드라인 정보를 정상적으로 확인할 수 있는 사건**으로 한정한다.

따라서 USSC 자료에서

* `SOURCES == 1`

에 해당하는 사건만을 분석한다.

연구기간은 FY2021–FY2025로 설정한다.

---

# 반응변수 정의

실제 선고결과는 다음 네 가지 유형으로 재분류한다.

* **0 = 무기징역/시형**
* **1 = 기간이 존재하는 형**
* **2 = 보호관찰 Only**
* **3 = Fine Only**

여기서 **기간이 존재하는 형**은 단순한 징역형만을 의미하지 않는다.

다음과 같이 실제 기간으로 측정 가능한 자유제한이 부과된 사건을 포함한다.

* Prison Only
* Prison + Alternative Confinement
* Probation + Alternative Confinement
* 기타 실제 자유제한 기간을 계산할 수 있는 혼합형

따라서 보호관찰에 Home Detention 등의 대체구금 조건이 포함되어 실제 제한기간이 존재하는 경우에는 **보호관찰 Only가 아니라 기간형**으로 분류한다.

반면 구금이나 대체구금 없이 보호관찰만 선고된 사건은 별도의 **보호관찰 Only** 범주로 구분한다.

Fine Only 역시 징역이나 보호관찰과 다른 실제 선고형태이므로 별도 범주로 유지한다.

---

# 분석 구조

분석은 크게 두 단계로 진행한다.

## 1단계: 형벌 유형 분류

현행 가이드라인 정보만을 이용하여 실제 선고가 다음 중 어느 유형인지 예측한다.

* 무기징역
* 기간형
* 보호관찰 Only
* Fine Only

이를 통해 현행 가이드라인이 실제 선고의 **형태 자체를 어느 정도 설명하는지** 평가한다.

## 2단계: 선고기간 예측

실제로 **기간형이 선고된 사건만을 대상으로** 실제 선고기간을 회귀모형으로 예측한다.

반응변수는 `SENSPLT0`을 중심으로 정의한다.

`SENSPLT0`은 단순한 실제 복역기간이 아니라 징역과 대체구금 등을 통합하여 측정한 기간이므로, 본 연구에서는 이를 **실제 선고기간 또는 자유제한 기간**으로 표현한다.

무기징역, 보호관찰 Only, Fine Only 사건은 선고기간 회귀분석에서 제외한다.

---

# 연구 목적

본 연구는 미국 연방 양형가이드라인이 제공하는 정보가 실제 형벌의 **유형과 기간을 얼마나 설명하고 예측할 수 있는지 평가하는 것**을 목적으로 한다.

먼저 `GLMIN`, `GLMAX`, `ZONE` 등 현행 가이드라인 정보만을 이용하여 Baseline 모델을 구축한다.

Baseline은 다음 두 종류의 모델로 구성한다.

1. 실제 형벌이 무기징역, 기간형, 보호관찰 Only, Fine Only 중 어느 유형인지 예측하는 **분류모델**
2. 기간형이 실제로 선고된 사건에서 실제 선고기간을 예측하는 **회귀모델**

이를 통해 현행 가이드라인의 설명력을 다음 두 측면으로 분리하여 평가한다.

* 실제로 **어떤 형태의 형벌이 선택되는가**
* 기간형이 선택된 경우 **얼마나 긴 기간이 선고되는가**

다음으로 실제 선고 이전에 확인 가능한 사건 특성을 이용하여 유사한 사건들을 군집화한다.

각 군집에서 Baseline 분류모델과 회귀모델의 성능을 비교하여 어떤 사건 유형에서 현행 가이드라인의 설명력이 상대적으로 낮게 나타나는지 확인한다.

설명력이 낮은 군집에서는 어떤 사건 특성이 형벌 유형 오분류 또는 큰 선고기간 예측오차와 관련되는지를 분석한다.

이를 통해 현행 가이드라인 정보만으로 충분히 설명되지 않는 실제 양형의 변동과 관련된 추가 정보를 탐색한다.

이후 발견된 후보 특성을 기존 가이드라인 정보에 추가한 확장 모델을 구축하고, Baseline 모델보다 실제 형벌 유형 및 선고기간 예측성능이 개선되는지 확인한다.

마지막으로 미래 연도 자료를 이용하여 이러한 성능 개선이 새로운 사건에서도 유지되는지 검증한다.

본 연구의 최종 목적은 새로운 법적 양형가이드라인을 직접 제안하는 것이 아니라, **현행 가이드라인 정보만으로 설명되지 않는 실제 양형의 변동을 확인하고 이를 추가적으로 설명할 수 있는 사건 정보를 탐색하는 것**이다.

# 연구 순서

## 1. 분석 대상 및 반응변수 정의

* FY2021–FY2025 사건 중 `SOURCES == 1`인 사건만을 분석한다.
* 실제 선고결과를 무기징역, 기간형, 보호관찰 Only, Fine Only의 네 범주로 재구성한다.
* 기간형 사건에서는 실제 선고기간을 별도의 연속형 반응변수로 정의한다.
* `GLMIN`, `GLMAX`, `ZONE` 등 공식 가이드라인 정보를 Baseline 설명변수로 설정한다.
* 실제 선고 이후 생성되는 정보는 설명변수에서 제외하여 타깃 누수를 방지한다.

---

## 2. Baseline 모델 구축

### 2-1. 형벌 유형 분류 Baseline

먼저 두 개의 Baseline을 비교한다.

**Baseline Classification A**

* 설명변수: `GLMIN`, `GLMAX`
* 반응변수: 실제 형벌 유형 Class

**Baseline Classification B**

* 설명변수: `GLMIN`, `GLMAX`, `ZONE`
* 반응변수: 실제 형벌 유형 Class

이를 통해 최종 권고 형량 범위만 이용한 경우와 ZONE까지 함께 고려한 경우를 비교한다.

분류성능은 다음 지표를 중심으로 평가한다.

* Confusion Matrix
* Accuracy
* Macro F1
* Class별 Precision
* Class별 Recall

무기징역이나 Fine Only처럼 빈도가 낮을 가능성이 있는 범주가 존재하므로 Accuracy만으로 모델을 평가하지 않고 **Macro F1 및 범주별 성능을 함께 평가한다.**

---

### 2-2. 선고기간 회귀 Baseline

실제로 **Class 1 = 기간형**이 관찰된 사건만을 대상으로 회귀분석을 수행한다.

반응변수:

* `SENSPLT0`

먼저 다음 두 Baseline을 비교한다.

**Baseline Regression A**

* 설명변수: `GLMIN`, `GLMAX`

**Baseline Regression B**

* 설명변수: `GLMIN`, `GLMAX`, `ZONE`

이를 통해 ZONE이 형벌 유형뿐만 아니라 실제 선고기간 설명에도 추가적인 정보를 제공하는지 확인한다.

회귀성능은 다음 지표를 이용한다.

* MAE
* RMSE
* R²

분류 Baseline과 회귀 Baseline을 이후 모든 확장모델의 비교 기준으로 사용한다.

---

## 3. 사건 특성 기반 군집화

실제 선고 이전에 확인할 수 있는 사건 및 피고인 특성을 이용하여 유사한 사건들을 군집화한다.

군집화에는 다음 정보를 사용하지 않는다.

* 실제 형벌 유형
* 실제 선고기간
* Baseline 모델의 예측값
* Baseline 모델의 예측오차
* 실제 선고 이후 생성되는 정보

군집은 실제 선고결과를 이용해 만들어지는 것이 아니라, **사건 자체의 사전적 특성에 따라 잠재적인 사건 유형을 구성하는 목적으로 사용한다.**

1차 군집화 후보 피처:

* `PRESENT`
* `NEWCNVTN`
* `DISTRICT`
* `CITIZEN`
* `AGE`
* `NEWEDUC`

이후 변수의 의미, 결측률, 가이드라인 반영 여부, 타깃 누수 가능성을 검토하여 군집화 변수를 확장하거나 축소한다.

---

## 4. 군집별 Baseline 성능 비교

각 군집에서 가이드라인의 설명력을 두 측면으로 평가한다.

### 형벌 유형

* Accuracy
* Macro F1
* Class별 Recall
* Confusion Matrix
* 주요 오분류 유형

### 선고기간

* MAE
* RMSE
* R²

이를 통해 사건 군집을 다음과 같이 구분할 수 있다.

* 형벌 유형과 기간을 모두 잘 설명하는 군집
* 형벌 유형은 잘 설명하지만 기간 예측력이 낮은 군집
* 기간은 비교적 잘 설명하지만 형벌 유형 선택을 잘 설명하지 못하는 군집
* 형벌 유형과 기간 모두에서 설명력이 낮은 군집

---

## 5. 예측오차 원인 분석

가이드라인의 설명력이 상대적으로 낮은 군집을 중심으로 추가 분석을 진행한다.

### 분류모델

* 어떤 특성을 가진 사건에서 형벌 유형 오분류가 많이 발생하는지 확인한다.
* 어떤 실제 형벌 유형 사이에서 오분류가 집중되는지 분석한다.
* 특정 사건 특성에서 일정한 방향의 오분류가 반복되는지 확인한다.

### 회귀모델

* 어떤 특성을 가진 사건에서 선고기간 예측오차가 크게 발생하는지 확인한다.
* 실제 선고기간이 Baseline 예측보다 체계적으로 길어지는 사건 특성을 탐색한다.
* 실제 선고기간이 Baseline 예측보다 체계적으로 짧아지는 사건 특성을 탐색한다.

이를 통해 현행 가이드라인이 충분히 포착하지 못할 가능성이 있는 사건 정보를 찾는다.

---

## 6. 추가 피처 검증

오차 분석에서 발견된 후보 특성을 기존 가이드라인 정보에 하나씩 또는 단계적으로 추가한다.

### 분류모델

Baseline Classification과 추가 특성을 포함한 Extended Classification을 비교한다.

확인할 내용:

* Macro F1 개선 여부
* Class별 Recall 개선 여부
* 특정 오분류 감소 여부

### 회귀모델

Baseline Regression과 추가 특성을 포함한 Extended Regression을 비교한다.

확인할 내용:

* MAE 감소 여부
* RMSE 감소 여부
* R² 증가 여부

추가 피처는 단순히 Baseline 오차와 상관관계가 있다는 이유만으로 선택하지 않는다.

**Validation 데이터에서 실제 out-of-sample 예측성능을 개선하는지**를 기준으로 판단한다.

---

## 7. 군집별 성능 개선 확인

추가 특성의 효과가 전체 사건에 동일하게 나타나는지 확인한다.

특히 기존 가이드라인의 설명력이 낮았던 군집에서 추가 특성이

* 형벌 유형 분류성능을 개선하는지
* 선고기간 예측오차를 감소시키는지

확인한다.

이를 통해 어떤 추가 정보가 **어떤 사건 유형에서 특히 유용한지** 평가한다.

---

## 8. 미래 연도 검증

과거 연도의 데이터로 모델을 학습하고 미래 연도의 데이터를 이용하여 성능을 검증한다.

다음 결과가 새로운 데이터에서도 유지되는지 확인한다.

* 형벌 유형 분류성능 개선
* 기간형 사건의 선고기간 예측성능 개선
* 특정 군집에서 확인된 성능 개선의 재현

이를 통해 추가 사건정보의 효과가 특정 연도에만 나타나는 현상인지, 새로운 사건에서도 일반화되는지를 검증한다.

---

## 9. 결론

최종적으로 다음 질문에 답한다.

* 현행 가이드라인은 실제 형벌 유형을 얼마나 잘 설명하는가?
* 기간형 사건에서는 실제 선고기간을 얼마나 잘 설명하는가?
* 어떤 사건 유형에서 가이드라인의 설명력이 상대적으로 낮은가?
* 어떤 추가 사건정보가 이러한 예측오차와 관련되는가?
* 해당 정보를 추가하면 실제 예측성능이 개선되는가?
* 이러한 개선이 미래 사건에서도 유지되는가?

미래 연도에서도 반복적으로 성능을 개선하는 정보가 확인될 경우, 해당 정보를 **현행 연방 양형가이드라인의 경험적 예측 한계를 보완할 가능성이 있는 추가 정보**로 해석한다.

# 연구 구조

| 단계                                  | 핵심 질문                              | 분석 내용                                                     |
| ----------------------------------- | ---------------------------------- | --------------------------------------------------------- |
| **1. Outcome Definition**           | 실제 양형결과를 어떻게 정의할 것인가?              | 무기징역 / 기간형 / 보호관찰 Only / Fine Only로 재분류하고 기간형의 실제 선고기간 정의 |
| **2. Baseline Evaluation**          | 가이드라인 정보만으로 실제 양형을 얼마나 설명할 수 있는가?  | 형벌 유형 분류 Baseline + 기간형 사건의 선고기간 회귀 Baseline 구축           |
| **3. Clustering**                   | 사건 특성에 따라 어떤 잠재적 사건 유형이 존재하는가?     | 선고 이전 사건정보를 이용한 비지도학습 군집화                                 |
| **4. Cluster Evaluation**           | 가이드라인의 설명력은 사건 유형별로 어떻게 달라지는가?     | 군집별 분류성능 및 회귀성능 비교                                        |
| **5. Error Diagnosis**              | 가이드라인으로 설명되지 않는 오차는 어떤 특성과 관련되는가?  | 오분류 사건과 큰 선고기간 오차 사건의 특성 분석                               |
| **6. Extended Modeling**            | 어떤 추가 정보가 가이드라인의 예측력을 보완하는가?       | 기존 가이드라인 정보 + 추가 피처 모델 구축                                 |
| **7. Cluster-specific Improvement** | 추가 피처는 어떤 사건 유형에서 가장 효과적인가?        | 군집별 Baseline과 확장모델의 성능 개선폭 비교                             |
| **8. Temporal Validation**          | 추가 피처의 효과가 새로운 사건에서도 유지되는가?        | 과거 연도 학습 후 미래 연도 자료에서 외부검증                                |
| **9. Conclusion**                   | 어떤 정보가 현행 가이드라인의 경험적 예측 한계를 보완하는가? | 분류·회귀·군집·미래연도 검증 결과 종합                                    |

# 연구에서 하지 않는 것

본 연구에서는 `SENTRNGE`를 사용하여 공식적인 가이드라인 내·외 여부를 복원하거나 예측하지 않는다.

실제 선고기간이 단순히 `GLMIN`과 `GLMAX` 사이에 존재하는지를 공식적인 가이드라인 준수 여부로 간주하지 않는다.

보호관찰을 단순히 징역 0개월과 동일한 형벌로 취급하지 않는다.

Fine Only 역시 보호관찰과 다른 별도의 실제 선고유형으로 구분한다.

또한 대체구금을 법적으로 징역과 동일한 형벌이라고 해석하지 않는다. 다만 실제 기간으로 측정 가능한 자유제한이 존재한다는 연구상의 공통점을 기준으로 징역 및 혼합형과 함께 **기간형** 범주에 포함한다.

본 연구의 핵심은 **가이드라인 이탈 여부를 분류하는 것이 아니라, 현행 가이드라인 정보가 실제 형벌의 유형과 기간을 얼마나 설명하고 예측하는지를 평가하는 것**이다.

추가 사건 특성이 예측성능을 개선하더라도 이를 곧바로 해당 변수를 법적 양형가이드라인에 추가해야 한다는 의미로 해석하지 않는다.

본 연구에서 검증하는 것은 다음과 같다.

> **해당 사건정보가 현행 양형가이드라인에 포함된 정보 이상의 추가적인 실제 양형 예측정보를 가지고 있는가?**

따라서 최종 결과는 새로운 법적 양형가이드라인의 제안이 아니라, **현행 가이드라인의 경험적 설명·예측 한계를 진단하고 이를 보완할 가능성이 있는 정보를 탐색한 결과**로 해석한다.
