# 연구 주제

## 연방 양형가이드라인의 실제 선고형량 설명력과 추가 사건정보의 증분 예측가치 분석

**연방 양형가이드라인은 실제 선고형량을 어느 정도 설명하는가?
그 설명력이 특히 낮은 사건 유형은 무엇이며, 가이드라인 외의 사건 특성을 추가하면 실제 선고형량 예측력이 얼마나 개선되는가?**

---

# 연구 목적

본 연구는 미국 연방 양형가이드라인이 제공하는 정보를 기준으로 실제 선고형량에 대한 설명력과 예측력을 평가하는 것을 목적으로 한다.

먼저 `GLMIN`, `GLMAX`, `ZONE` 등 현행 가이드라인 정보를 이용하여 실제 선고형량을 예측하는 Baseline 모델을 구축한다. 이를 통해 가이드라인 정보만으로 실제 선고형량을 어느 정도 설명할 수 있는지 평가한다.

다음으로 실제 선고 이전에 확인할 수 있는 사건 특성을 이용하여 유사한 사건들을 군집화한다. 이후 각 군집에서 Baseline 모델의 예측오차를 비교하여, 어떤 사건 유형에서 가이드라인의 설명력이 상대적으로 낮게 나타나는지 확인한다.

가이드라인의 설명력이 낮은 군집에서는 어떤 사건 특성이 큰 예측오차와 관련되는지 분석한다. 이를 통해 현행 가이드라인 정보만으로 충분히 설명되지 않는 실제 양형의 변동과 관련된 추가 정보를 탐색한다.

이후 발견된 후보 특성을 기존 가이드라인 정보에 추가한 확장 모델을 구축한다. Baseline 모델과 확장 모델을 동일한 검증자료에서 비교하여 실제 선고형량 예측성능이 개선되는지 확인한다.

마지막으로 미래 연도의 데이터를 이용하여 이러한 성능 개선이 새로운 사건에서도 유지되는지 검증한다.

본 연구의 최종 목적은 새로운 법적 양형가이드라인을 직접 제시하는 것이 아니라, **현행 가이드라인 정보만으로 설명되지 않는 실제 양형의 변동을 확인하고 이를 추가적으로 설명할 수 있는 사건 정보를 탐색하는 것**이다.

---

# 연구 순서

1. **분석 대상 및 변수 정의**

   * 실제 선고형량을 예측 대상 변수로 설정한다.
   * `GLMIN`, `GLMAX`, `ZONE` 등 공식 가이드라인 정보를 Baseline 변수로 설정한다.
   * 실제 선고 이후 생성되는 정보와 타깃 누수 가능성이 있는 변수는 예측변수에서 제외한다.

2. **Baseline 모델 구축**

   * 현행 가이드라인 정보만을 이용하여 실제 선고형량을 예측한다.
   * MAE, RMSE, R² 등을 이용하여 전체 사건에서의 예측성능을 측정한다.
   * 이후 모든 확장 모델의 비교 기준으로 사용한다.

3. **사건 특성 기반 군집화**

   * 실제 선고 이전에 확인 가능한 사건 정보를 이용하여 유사한 사건들을 군집화한다.
   * 실제 선고형량이나 Baseline 모델의 예측오차는 군집 생성에 사용하지 않는다.

4. **군집별 Baseline 성능 비교**

   * 각 군집에서 Baseline 모델의 MAE, RMSE, R² 등을 계산한다.
   * 어떤 사건 유형에서 가이드라인의 실제 선고형량 설명력이 상대적으로 낮은지 확인한다.

5. **예측오차 원인 분석**

   * Baseline 모델의 예측오차가 큰 사건들을 분석한다.
   * 설명력이 낮은 군집에서 어떤 사건 특성이 큰 오차와 관련되는지 확인한다.
   * 실제 선고형량이 Baseline 예측보다 체계적으로 높거나 낮게 나타나는 특성이 존재하는지도 함께 분석한다.

6. **추가 피처 검증**

   * 오차 분석에서 발견된 후보 특성을 기존 가이드라인 정보에 하나씩 또는 단계적으로 추가한다.
   * Baseline 모델과 확장 모델의 예측성능을 동일한 검증자료에서 비교한다.
   * 단순히 통계적으로 관련성이 있는지가 아니라 실제로 새로운 사건의 예측오차를 줄이는지를 중심으로 평가한다.

7. **군집별 성능 개선 확인**

   * 추가 피처에 의한 성능 개선이 전체 사건에서 나타나는지 확인한다.
   * 특히 기존 가이드라인의 설명력이 낮았던 군집에서 성능 개선이 크게 나타나는지 분석한다.

8. **미래 연도 검증**

   * 과거 연도의 데이터로 모델을 학습한다.
   * 이후 연도의 데이터를 이용하여 Baseline 모델과 확장 모델을 다시 비교한다.
   * 추가 특성의 효과가 새로운 사건에서도 유지되는지 확인한다.

9. **결론**

   * 현행 가이드라인이 실제 선고형량을 어느 정도 설명하는지 정리한다.
   * 가이드라인의 설명력이 상대적으로 낮은 사건 유형을 확인한다.
   * 어떤 추가 사건 정보가 기존 가이드라인만으로 설명되지 않는 실제 양형의 변동을 추가적으로 설명하는지 평가한다.
   * 미래 연도에서도 효과가 유지되는 경우, 해당 정보를 현행 가이드라인의 경험적 예측 한계를 보완할 가능성이 있는 정보로 해석한다.

# 연구 구조

| 단계                                  | 핵심 질문                                  | 분석 내용                                  |
| ----------------------------------- | -------------------------------------- | -------------------------------------- |
| **1. Baseline Evaluation**          | 현행 가이드라인 정보만으로 실제 선고형량을 얼마나 설명할 수 있는가? | 가이드라인 정보를 이용한 Baseline 모델 구축 및 예측성능 평가 |
| **2. Clustering**                   | 사건 특성에 따라 어떤 잠재적 사건 유형이 존재하는가?         | 선고 이전 사건 정보를 이용한 비지도학습 군집화             |
| **3. Cluster Evaluation**           | 가이드라인의 설명력은 사건 유형별로 어떻게 달라지는가?         | 군집별 MAE, RMSE, R² 비교                   |
| **4. Error Diagnosis**              | 가이드라인으로 설명되지 않는 오차는 어떤 사건 특성과 관련되는가?   | 군집별 변수 분포와 예측오차 관련 요인 분석               |
| **5. Extended Modeling**            | 어떤 추가 사건 특성이 기존 가이드라인의 예측력을 보완하는가?     | 가이드라인 정보와 추가 피처를 결합한 회귀모델 구축           |
| **6. Cluster-specific Improvement** | 추가 피처의 효과는 어떤 사건 유형에서 가장 크게 나타나는가?     | 군집별 Baseline 모델과 확장 모델의 성능 개선폭 비교      |
| **7. Temporal Validation**          | 추가 피처의 효과가 새로운 사건에서도 유지되는가?            | 과거 연도 학습 후 미래 연도 데이터에서 성능 검증           |
| **8. Conclusion**                   | 어떤 정보가 현행 가이드라인의 경험적 예측 한계를 보완하는가?     | 전체 결과, 군집별 결과, 미래 연도 검증 결과 종합          |

# 핵심 비교

본 연구에서는 두 종류의 모델을 비교한다.

### Baseline Model

현행 연방 양형가이드라인이 제공하는 정보만을 이용하여 실제 선고형량을 예측한다.

주요 후보 변수:

* `GLMIN`
* `GLMAX`
* `ZONE`
* 기타 가이드라인을 구성하거나 직접 나타내는 정보

### Extended Model

Baseline Model에 가이드라인 외의 추가 사건 특성을 결합한다.

핵심적으로 확인할 것은 다음과 같다.

* MAE가 감소하는가?
* RMSE가 감소하는가?
* R²가 증가하는가?
* 이러한 개선이 특정 군집에서 특히 크게 나타나는가?
* 미래 연도의 사건에서도 개선이 유지되는가?

# 연구에서 하지 않는 것

본 연구에서는 `SENTRNGE`를 사용하여 공식적인 가이드라인 내·외 여부를 복원하거나 예측하지 않는다.

또한 실제 선고형량이 단순히 `GLMIN`과 `GLMAX` 사이에 존재하는지를 공식적인 가이드라인 준수 여부로 간주하지 않는다.

본 연구의 핵심은 **가이드라인 이탈 여부를 분류하는 것이 아니라, 현행 가이드라인 정보가 실제 선고형량을 얼마나 설명하고 예측하는지를 평가하는 것**이다.

추가 사건 특성이 예측성능을 개선하더라도 이를 곧바로 해당 변수를 양형가이드라인에 추가해야 한다는 의미로 해석하지 않는다.

본 연구에서 검증하는 것은 다음과 같다.

> **해당 사건 정보가 현행 양형가이드라인에 포함된 정보 이상의 추가적인 실제 양형 예측정보를 가지고 있는가?**

따라서 최종 결과는 새로운 법적 양형가이드라인의 제안이 아니라, **현행 가이드라인의 경험적 설명·예측 한계를 진단하고 이를 보완할 가능성이 있는 정보를 탐색한 결과**로 해석한다.
