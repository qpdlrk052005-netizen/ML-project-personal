# 연구 주제

## 연방 양형가이드라인의 실제 형벌 유형 및 선고기간 설명력과 추가 사건정보의 증분 예측가치 분석

**연방 양형가이드라인은 실제 형벌 유형과 선고기간을 어느 정도 설명하는가?
그 설명력은 사건 유형에 따라 어떻게 달라지며, 가이드라인 외의 사건정보를 추가하면 실제 양형에 대한 예측력을 얼마나 개선할 수 있는가?**

본 연구에서는 실제 양형결과를 **형벌 유형**과 **선고기간**이라는 두 측면으로 나누어 분석한다.

먼저 가이드라인 정보만을 이용하여 실제 형벌 유형과 선고기간에 대한 Baseline을 구축한다.

이후 실제 선고 이전에 확인 가능한 사건 특성을 이용하여 유사한 사건들을 군집화하고, 각 군집에서 가이드라인의 예측력이 어떻게 달라지는지 확인한다.

마지막으로 추가 사건정보를 가이드라인 정보와 결합하여 전체 및 각 군집에서 실제 양형에 대한 예측력이 얼마나 개선되는지 평가한다.

---

# 연구 대상

연구 대상은 USSC Individual Datafile의 FY2021–FY2025 사건 중 **연방 양형가이드라인 정보를 정상적으로 확인할 수 있는 사건**으로 한정한다.

따라서

* `SOURCES == 1`

인 사건만을 분석한다.

---

# 반응변수

실제 양형결과는 두 가지 측면에서 분석한다.

## 1. 형벌 유형

실제 선고결과를 다음 네 가지 유형으로 구분한다.

* **0 = 무기징역**
* **1 = 기간형**
* **2 = 보호관찰 Only**
* **3 = Fine Only**

여기서 **기간형**은 단순한 징역형뿐 아니라 실제 기간으로 측정 가능한 자유제한이 존재하는 선고를 포함한다.

따라서 다음과 같은 경우를 기간형에 포함한다.

* Prison Only
* Prison + Alternative Confinement
* Probation + Alternative Confinement

반면 대체구금 없이 보호관찰만 선고된 사건은 **보호관찰 Only**, 징역이나 보호관찰 없이 벌금만 부과된 사건은 **Fine Only**로 구분한다.

---

## 2. 기간형의 선고기간

실제로 **기간형이 선고된 사건**에서는 실제 선고기간을 별도로 분석한다.

반응변수는

* `SENSPLT0`

을 사용한다.

`SENSPLT0`은 징역 및 대체구금 등 실제 기간으로 측정 가능한 자유제한을 종합한 변수이므로 본 연구에서는 이를 **실제 선고기간 또는 자유제한 기간**으로 사용한다.

---

# 분석 구조

본 연구는 형벌 유형과 선고기간을 서로 다른 두 분석으로 다룬다.

## Track A. 형벌 유형

전체 사건을 대상으로 실제 선고가

* 무기징역
* 기간형
* 보호관찰 Only
* Fine Only

중 어느 유형에 해당하는지 분석한다.

가이드라인 정보만을 이용한 Baseline과 추가 사건정보를 포함한 모델을 비교하여 **형벌 유형에 대한 예측력이 얼마나 개선되는지** 평가한다.

주요 평가 기준은

* Macro F1
* Class별 Precision
* Class별 Recall
* Class별 F1
* Confusion Matrix

이다.

---

## Track B. 기간형 선고기간

실제로 **기간형이 선고된 사건만을 대상**으로 실제 선고기간을 분석한다.

가이드라인 정보만을 이용한 Baseline과 추가 사건정보를 포함한 모델을 비교하여 **실제 선고기간에 대한 예측력이 얼마나 개선되는지** 평가한다.

주요 평가 기준은

* MAE
* RMSE
* R²

이다.

형벌 유형 분류 결과를 선고기간 회귀분석으로 전달하지 않으며, 기간형 분석에는 **실제로 기간형이 관찰된 사건**을 사용한다.

---

# 사건 특성 기반 군집화

실제 선고 이전에 확인할 수 있는 사건 및 피고인 특성을 이용하여 유사한 사건들을 군집화한다.

군집화의 목적은 단순히 사건을 여러 집단으로 나누는 것이 아니라,

> **가이드라인의 실제 양형 예측력이 어떤 종류의 사건에서 높거나 낮게 나타나는지 확인하는 것**

이다.

1차 군집화 후보 변수는 다음과 같다.

* `PRESENT`
* `NEWCNVTN`
* `DISTRICT`
* `CITIZEN`
* `AGE`
* `NEWEDUC`

군집화에는 실제 형벌 유형, 실제 선고기간 또는 모델의 예측결과를 사용하지 않는다.

---

# 군집별 가이드라인 설명력

각 군집에서 가이드라인만을 이용한 Baseline의 성능을 비교한다.

### 형벌 유형

* Macro F1
* Class별 Recall 및 F1
* Confusion Matrix

### 선고기간

* MAE
* RMSE
* R²

이를 통해 가이드라인 정보가 실제 양형을 비교적 잘 설명하는 사건군과 그렇지 않은 사건군을 구분한다.

---

# 추가 사건정보의 증분 예측가치

가이드라인 정보만을 이용한 모델과 추가 사건정보를 포함한 모델을 비교한다.

핵심 비교는 다음과 같다.

> **Guideline-only Model**
> vs.
> **Guideline + Additional Case Information Model**

### 형벌 유형

추가 사건정보가

* 전체 Macro F1을 얼마나 증가시키는지
* 각 형벌 유형의 F1과 Recall을 얼마나 개선하는지
* 주요 오분류를 얼마나 감소시키는지

평가한다.

### 선고기간

추가 사건정보가

* MAE를 얼마나 감소시키는지
* RMSE를 얼마나 감소시키는지
* R²를 얼마나 증가시키는지

평가한다.

또한 이러한 개선폭을 군집별로 비교하여 **어떤 사건 유형에서 추가 사건정보의 가치가 특히 크게 나타나는지** 확인한다.

---

# 연구 목적

본 연구의 목적은 새로운 법적 양형기준을 직접 제안하는 것이 아니다.

핵심은

> **현행 연방 양형가이드라인이 실제 형벌의 유형과 기간을 어느 정도 설명하는지, 그 설명력이 사건 유형별로 어떻게 달라지는지, 그리고 추가 사건정보가 가이드라인만으로 설명되지 않는 실제 양형의 변동을 얼마나 추가적으로 설명할 수 있는지 확인하는 것**

이다.

따라서 최종적으로 다음 세 가지 질문에 답한다.

1. **가이드라인은 실제 형벌 유형과 기간형 선고기간을 얼마나 잘 설명하는가?**
2. **가이드라인의 설명력은 사건 특성에 따라 구성된 군집 사이에서 어떻게 달라지는가?**
3. **추가 사건정보는 전체 및 각 군집에서 실제 양형에 대한 예측력을 얼마나 개선하는가?**

추가 사건정보의 효과는 단순한 상관관계가 아니라 **가이드라인 정보만을 이용한 Baseline 대비 실제 예측성능의 개선**을 기준으로 평가한다.

---

# 프로젝트 과정
  1. 분석 대상 및 설명/반응변수 정의
     - 형벌 유형 분류기 A - 설명변수 = 'GLMIN','GLMAX'
     - 형벌 유형 분류기 B - 설명변수 = 'GLMIN','GLMAX','ZONE'
     - 분류기 반응변수('Class') = 0 - 무기징역/사형 // 1 - 실제 자유 제한 기간이 있는 경우 // 2 - 보호관찰만 // 3-벌금형
    
     - 설명변수가 1일 경우 - 실제 자유 제한 기간을 예측하는 baseline 회귀모델로 예측
     - baseline 회귀모델 - 설명변수 = 'GLMIN','GLMAX', ... 반응변수 = 실제 자유 제한 기간

     - 군집화 피처 = 'PRESENT','NEWCNVTN','DISTRICT','CITIZEN','AGE','NEWEDUC' ( 1차 )
    
     # 데이터 전처리
       - 'Class' 열 생성
       - 'GLMIN','GLMAX'에 특수값 존재 -> 특수값인 경우를 nan처리한 'GLMIN_MONTH','GLMAX_MONTH' 생성 ( 나중에 파이프라인으로 nan 대체 -> 미리 대체하면 데이터 누수 )
       - 'GLMIN_LIFE',"GLMAX_LIFE'도 생성해서, 9996일 때 1인 범주형 변수 만들기.
       - 'GLMIN_ZERO'도 만들어서, GLMIN==0일 때 보호관찰을 허용한다는 점을 이용하기.

      - 모델 평가 기준
