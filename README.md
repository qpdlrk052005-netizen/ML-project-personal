# 연구 주제
연방 양형가이드라인은 실제 양형을 얼마나 잘 설명하며, 어떤 사건 특성을 추가하면 미래 양형 및 가이드라인 이탈 예측을 개선할 수 있는가?

# 연구 목적
지금 가이드라인이 실제 양형을 설명하기에 충분한지 확인하고, 부족하다면 어떤 사건에서 왜 부족한지 찾아본 뒤, 그 정보를 추가하면 실제로 더 잘 예측할 수 있는지 확인하는 연구이다.

# 연구 순서
0.  유효한 가이드라인을 확보하기 어려운 사건인가? (지도학습 분류기)
1.	현재 가이드라인이 실제 양형과 얼마나 잘 맞는가?
2.	선고 전에 알 수 있는 사건 정보들을 바탕으로 비슷한 사건끼리 묶는다.(비지도학습 군집화)
3.	가이드라인이 잘 맞지 않는 사건 유형을 찾는다.
4.	해당 사건 유형을 다시 보면서, 어떤 변수들이 유형을 특징짓는지 찾는다.
5.	발견한 변수들을 가이드라인 정보에 하나씩 논리적으로 추가하면서 실제 형량 및 이탈 예측 성능이 개선되는 지 확인한다.(지도학습 Regression)
6.	미래 사건에서도 성능 개선이 유지되는 지 검토한다
7.	어떤 정보가 기존 가이드라인의 예측 한계를 보완할 가능성이 있는 지 결론 낸다.

# 연구 구조
| Step | 핵심 질문 | 방법 |
|---|---|---|
| **1. Gate** | 유효한 단일 guideline range를 사전에 확보 가능한 사건인지 판별할 수 있는가? | `SOURCES ∈ {6,7,8,9}` 가능성 분류 |
| **2. Clustering** | 일반 사건 안에 어떤 잠재적 사건 유형이 존재하는가? | 비지도학습 |
| **3. Evaluation** | 어떤 군집에서 현행 guideline이 특히 잘 맞지 않는가? | `GLMIN~GLMAX` vs 실제 양형 |
| **4. Diagnosis** | 해당 군집에서 무엇을 놓치고 있는가? | 군집 특성 비교 |
| **5. Modification** | 어떤 변수·조정구조를 추가해야 하는가? | Guideline 수정 |
| **6. Validation** | 수정된 guideline이 실제로 더 나은가? | 미래연도 데이터 검증 |
             
# 사용 데이터
Train- 21~23년도
validation - 24년도
test - 25년도

# 프로젝트 설계
setup - 21~25년도의 열 추출 -> 공통된 열만 사용한다.(연구의 통일성을 위함)
      - 가이드라인을 양형 선고 전에 구할 수 있는 대상이여야 한다.

1. 현재 가이드라인이 실제 양형과 얼마나 잘 맞는가?
   - 21~25년도의 예상 양형 구간에 실제 형이 포함되어 있는 지?
   - GLMIN,GLMAX는 최종적으로 내려진 최종 가이드라인의 범위. SENTTCAP은 실제 양형 
   - 다수의 결측치 발견 -> SENTTCAP의 결측치는 보호관찰 일 때임. -> '실제 징역'을 받은 사람들만 대상으로 조사 -> 결과를 이용한 표본 선택 문제 발생
   - 보호관찰일 때도 다뤄 보자. -> SENSCAP 변수 사용
     
| 실제 선고             | `SENSPCAP` |
| ----------------- |  ---------: |
| 징역 24개월           |         24 |
| 징역 4개월 + 가택구금 4개월 |          8 |
| 보호관찰만 선고          |      **0** |
| 종신형               |    **470** |
| 470개월 초과 유기징역     | **469.99** |
| 진짜 결측/판정불가/해당없음   |        NaN |
   - 예측 보호관찰 -> 양형 보호관찰인 경우는 관찰되지 않음. -> 그렇다면 GLMIN이 0일 때 보호관찰도 가능하다.. 임을 포함하는가? -> 맞다. -> 그렇다면 GLMIN<=SENSPCAP<=GLMAX면 문제 없을 것.
   - 새로운 변수를 지정했으니, 새로이 결측치 처리를 해야 함. -> SENSPCAP은 결측치가 하나라서 drop했다. -> 300~600개의 GLMIN,GLMAX결측치는 무엇을 의미하는가? -> SOURCES 변수
   - SOURCES변수가 6,7,8,9일 때는 결측이 생길 수 있다고 코드북에 명시 -> 직접 돌려보니 사실이였음
   - 결측치를 어떻게 다룰 것인가?
   - SOURCES == 6 -> 법률에 정해진 statutory provision을 중심으로 선고가 이루어지는 사건
   - SOURCES == 7 -> 일반적인 guideline application 정보 없이 statutory provision이 적용되는 사건
   - SOURCES == 8 -> 유사한 연방 양형지침(analogous guideline)이 없는 사건
   - SOURCES == 9 -> ① PSR이 면제되었거나, ② PSR이 누락되었거나, ③ 최종 offense level이 여러 개 존재하는 경우다. 단일 정보를 확정할 수 없는 사건이다.
   - 연구 목적은 "기존에 알려진 가이드라인 계산"이므로, 연구 대상을 확실히 '가이드라인을 알 수 있는 대상'으로 한정하자.
   - 따라서 SOURCES가 6,7,8,9에 해당하는 사건인 지 아닌 지 구분 할 수 있는 분류기를 먼저 배치해보자.
   - GLMIN<=SENSPCAP<=GLMAX의 비율 즉. 실제 선고가 가이드라인 범위 내에 포괄되는 비율을 알아보자.
   - 종속변수 -> SENTRNGE==0 (가이드라인 범위에 포함) 의 빈도가 가이드라인 내 포함 과 오차가 컸다. 가이드라인 판정 변수를 다시 검토해야할듯.
