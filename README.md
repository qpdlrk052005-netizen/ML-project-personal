# 연구 주제

연방 양형가이드라인은 실제 선고형량을 얼마나 잘 설명하며, 그 설명력은 사건 유형별로 어떻게 달라지는가? 또한 가이드라인만으로 충분히 설명되지 않는 사건에서 어떤 추가적인 사건 특성이 예측 성능을 개선할 수 있는가?

# 연구 목적

먼저 현행 연방 양형가이드라인의 권고 형량 범위와 실제 선고형량을 비교하여, 가이드라인이 실제 양형을 얼마나 잘 설명하는지 평가한다.

이후 선고 이전에 확인 가능한 사건 특성을 이용하여 유사한 사건들을 군집화하고, 각 군집에서 가이드라인의 실제 선고형량 설명력이 어떻게 달라지는지 비교한다.

가이드라인의 설명력이 상대적으로 낮은 군집을 대상으로 어떤 사건 특성이 큰 예측오차와 관련되어 있는지 분석한다.

마지막으로 발견된 추가 특성을 기존 가이드라인 정보에 추가한 예측모델을 구축하고, 실제 선고형량 예측 성능이 개선되는지 검증한다. 이후 미래 연도 자료에서도 이러한 성능 개선이 유지되는지를 확인하여, 기존 가이드라인의 예측 한계를 보완할 가능성이 있는 정보를 탐색한다.

# 연구 순서
현행 연방 양형가이드라인은 실제 선고형량을 얼마나 잘 설명하는지 평가한다.
선고 이전에 확인 가능한 사건 정보를 이용하여 유사한 사건들을 군집화한다.
군집별로 가이드라인의 실제 선고형량 예측오차를 비교한다.
가이드라인의 설명력이 상대적으로 낮은 군집에서 어떤 사건 특성이 큰 오차와 관련되어 있는지 분석한다.
발견된 추가 특성을 기존 가이드라인 정보에 하나씩 추가하여 실제 선고형량 예측 성능이 개선되는지 확인한다.
미래 연도 자료에서 성능 개선이 유지되는지 검증한다.
어떤 사건 정보가 기존 양형가이드라인의 실제 선고형량 예측 한계를 보완할 가능성이 있는지 결론을 내린다.

# 연구 구조
1. Baseline Evaluation	현행 가이드라인은 전체 사건에서 실제 선고형량을 얼마나 잘 설명하는가?	GLMIN, GLMAX, ZONE 등 가이드라인 정보와 실제 선고형량 비교 및 Baseline 모델 구축
2. Clustering	사건 특성에 따라 어떤 잠재적 사건 유형이 존재하는가?	선고 이전 사건 정보를 이용한 비지도학습 군집화
3. Cluster Evaluation	가이드라인의 설명력은 사건 유형별로 어떻게 달라지는가?	군집별 MAE, RMSE, R² 등 예측성능 비교
4. Diagnosis	설명력이 낮은 군집은 어떤 특성을 가지고 있는가?	군집 간 변수 분포 및 예측오차 관련 요인 비교
5. Extended Modeling	어떤 추가 사건 특성이 가이드라인의 예측력을 보완하는가?	기존 가이드라인 정보 + 추가 피처를 이용한 회귀모델 구축
6. Validation	추가 피처에 의한 성능 개선이 새로운 사건에서도 유지되는가?	미래 연도 데이터에서 Baseline 모델과 확장모델 비교
7. Conclusion	어떤 정보가 현행 가이드라인의 예측 한계를 보완할 가능성이 있는가?	군집별 결과와 외부 검증 결과 종합

# 사용 데이터
