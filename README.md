# 연구 주제

## 연방 양형가이드라인의 실제 형벌 유형 및 선고기간 설명력과 추가 사건정보의 증분 예측가치 분석

**연방 양형가이드라인은 실제 형벌 유형과 선고기간을 어느 정도 설명하는가?
그 설명력이 특히 낮은 사건 유형은 무엇이며, 가이드라인 외의 사건 특성을 추가하면 실제 양형에 대한 예측력을 얼마나 개선할 수 있는가?**

---

# 반응변수 정의

실제 선고결과는 먼저 다음 세 가지 유형으로 구분한다.

* **0 = 무기징역**
* **1 = 기간이 존재하는 형**
* **2 = 보호관찰 Only**

여기서 **기간이 존재하는 형**은 단순 징역형뿐 아니라 실제 기간으로 측정 가능한 대체구금 및 혼합형을 포함한다.

따라서 분석은 두 단계로 진행한다.

### 1단계: 형벌 유형 분류

현행 가이드라인 정보를 이용하여 실제 선고가 다음 중 어느 유형에 해당하는지 예측한다.

* 무기징역
* 기간이 존재하는 형
* 보호관찰 Only

### 2단계: 선고기간 예측

실제로 **기간이 존재하는 형을 받은 사건만을 대상으로** 실제 선고기간을 회귀모형으로 예측한다.

실제 기간은 징역과 대체구금 등을 통합하여 측정할 수 있는 `SENSPLT0`을 중심으로 정의한다.

Fine Only 등 위 세 범주에 포함되지 않는 선고형태는 빈도와 연구 목적을 확인한 뒤 분석대상에서 별도로 처리한다.

---

# 연구 목적

본 연구는 미국 연방 양형가이드라인이 제공하는 정보가 실제 형벌의 **유형과 기간을 얼마나 설명하고 예측할 수 있는지 평가하는 것**을 목적으로 한다.

먼저 `GLMIN`, `GLMAX`, `ZONE` 등 현행 가이드라인 정보만을 이용하여 Baseline 모델을 구축한다.

Baseline 모델은 두 부분으로 구성된다.

1. 실제 형벌이 무기징역, 기간형, 보호관찰 중 어느 유형인지 예측하는 **분류모델**
2. 기간형이 실제로 선고된 사건에서 그 기간을 예측하는 **회귀모델**

이를 통해 가이드라인이 실제 선고를 설명하는 능력을 **형벌 유형 선택과 선고기간 결정으로 구분하여 평가**한다.

다음으로 실제 선고 이전에 확인 가능한 사건 특성을 이용하여 유사한 사건들을 군집화한다. 각 군집에서 Baseline 분류모델과 회귀모델의 성능을 비교하여 어떤 사건 유형에서 가이드라인의 설명력이 상대적으로 낮은지 확인한다.

설명력이 낮은 군집에서는 어떤 사건 특성이 분류오류 또는 큰 선고기간 예측오차와 관련되는지를 분석한다. 이를 통해 현행 가이드라인 정보만으로 충분히 설명되지 않는 실제 양형의 변동과 관련된 추가 정보를 탐색한다.

이후 발견된 후보 특성을 기존 가이드라인 정보에 추가한 확장 모델을 구축하고, Baseline 모델보다 실제 형벌 유형 및 선고기간 예측성능이 개선되는지 확인한다.

마지막으로 미래 연도 자료를 이용하여 이러한 성능 개선이 새로운 사건에서도 유지되는지 검증한다.

본 연구의 최종 목적은 새로운 법적 양형가이드라인을 직접 제안하는 것이 아니라, **현행 가이드라인 정보만으로 설명되지 않는 실제 양형의 변동을 확인하고 이를 추가적으로 설명할 수 있는 사건 정보를 탐색하는 것**이다.

---

# 연구 순서

## 1. 분석 대상 및 반응변수 정의

* 실제 선고결과를 무기징역, 기간형, 보호관찰 Only의 세 범주로 구분한다.
* 기간형 사건에서는 실제 선고기간을 별도의 연속형 반응변수로 정의한다.
* `GLMIN`, `GLMAX`, `ZONE` 등 공식 가이드라인 정보를 Baseline 설명변수로 설정한다.
* 실제 선고 이후 생성되는 정보와 타깃 누수 가능성이 있는 변수는 예측변수에서 제외한다.

---

## 2. Baseline 모델 구축

### 형벌 유형 분류

현행 가이드라인 정보만을 이용하여 다음 세 가지 실제 선고유형을 예측한다.

* 무기징역
* 기간형
* 보호관찰 Only

분류성능은 혼동행렬, Accuracy, Macro F1, class별 Precision 및 Recall 등을 이용하여 평가한다.

특히 무기징역과 같이 빈도가 낮은 범주가 존재할 수 있으므로 전체 Accuracy뿐 아니라 **범주별 성능과 Macro F1을 함께 평가한다.**

### 선고기간 회귀

실제로 기간형이 선고된 사건만을 대상으로 실제 선고기간을 예측한다.

MAE, RMSE, R² 등을 이용하여 가이드라인 정보만으로 실제 기간을 어느 정도 설명할 수 있는지 평가한다.

이 두 모델을 이후 모든 분석의 Baseline으로 사용한다.

---

## 3. 사건 특성 기반 군집화

* 실제 선고 이전에 확인 가능한 사건 정보를 이용하여 유사한 사건들을 군집화한다.
* 실제 선고유형, 실제 선고기간, Baseline 모델의 예측오차는 군집 생성에 사용하지 않는다.
* 군집은 가이드라인의 성능을 평가하기 위한 사후 분석단위로 사용한다.

---

## 4. 군집별 Baseline 성능 비교

각 군집에서 가이드라인의 설명력을 두 측면으로 평가한다.

### 형벌 유형

* 분류 정확도
* Macro F1
* 범주별 Recall
* 오분류 구조

### 선고기간

* MAE
* RMSE
* R²

이를 통해 다음과 같은 사건 유형을 구분한다.

* 형벌 유형과 기간을 모두 잘 설명하는 군집
* 형벌 유형은 잘 설명하지만 기간 예측력이 낮은 군집
* 기간은 비교적 잘 설명하지만 형벌 유형 선택을 잘 설명하지 못하는 군집
* 두 가지 모두 설명력이 낮은 군집

---

## 5. 예측오차 원인 분석

가이드라인의 설명력이 상대적으로 낮은 군집을 중심으로 추가 분석을 진행한다.

### 분류모델

* 어떤 특성을 가진 사건에서 형벌 유형 오분류가 많이 발생하는지 확인한다.
* 어떤 실제 형벌 유형 사이에서 오분류가 집중되는지 확인한다.

### 회귀모델

* 어떤 특성을 가진 사건에서 선고기간 예측오차가 크게 발생하는지 확인한다.
* 실제 선고기간이 Baseline 예측보다 체계적으로 길거나 짧아지는 사건 특성이 존재하는지 분석한다.

이를 통해 현행 가이드라인이 충분히 포착하지 못하고 있을 가능성이 있는 사건 정보를 탐색한다.

---

## 6. 추가 피처 검증

오차 분석에서 발견된 후보 특성을 기존 가이드라인 정보에 하나씩 또는 단계적으로 추가한다.

### 분류모델

Baseline 분류모델과 추가 특성을 포함한 확장 분류모델을 비교한다.

### 회귀모델

Baseline 회귀모델과 추가 특성을 포함한 확장 회귀모델을 비교한다.

단순히 특정 변수가 통계적으로 관련되는지만 확인하는 것이 아니라, **동일한 검증자료에서 실제 예측성능을 개선하는지**를 중심으로 평가한다.

---

## 7. 군집별 성능 개선 확인

추가 특성의 효과가 모든 사건에서 동일하게 나타나는지 확인한다.

특히 기존 가이드라인의 설명력이 낮았던 군집에서 추가 특성이

* 형벌 유형 분류성능을 개선하는지
* 선고기간 예측오차를 감소시키는지

확인한다.

이를 통해 어떤 정보가 어떤 종류의 사건에서 특히 유용한지를 분석한다.

---

## 8. 미래 연도 검증

과거 연도의 데이터를 이용하여 Baseline 모델과 확장 모델을 학습한다.

이후 미래 연도의 사건을 이용하여 두 모델을 비교한다.

다음 두 결과가 모두 새로운 데이터에서도 유지되는지 확인한다.

* 형벌 유형 분류성능 개선
* 기간형 사건의 선고기간 예측성능 개선

이를 통해 추가 사건정보의 효과가 특정 연도의 데이터에만 나타나는 현상인지, 새로운 사건에서도 재현되는지를 검증한다.

---

## 9. 결론

최종적으로 다음 질문에 답한다.

* 현행 가이드라인은 실제 형벌 유형을 얼마나 잘 설명하는가?
* 기간형 사건에서는 실제 선고기간을 얼마나 잘 설명하는가?
* 어떤 사건 유형에서 가이드라인의 설명력이 상대적으로 낮은가?
* 어떤 추가 사건정보가 이러한 예측오차와 관련되는가?
* 해당 정보를 추가하면 실제 예측성능이 개선되는가?
* 이러한 개선이 미래 사건에서도 유지되는가?

미래 연도에서도 반복적으로 성능을 개선하는 정보가 확인될 경우, 해당 정보를 **현행 연방 양형가이드라인의 경험적 예측 한계를 보완할 가능성이 있는 추가 정보**로 해석한다.

| 단계                                  | 핵심 질문                              | 분석 내용                                       |
| ----------------------------------- | ---------------------------------- | ------------------------------------------- |
| **1. Outcome Definition**           | 실제 양형결과를 어떻게 정의할 것인가?              | 무기징역 / 기간형 / 보호관찰 Only 분류 및 기간형의 실제 선고기간 정의 |
| **2. Baseline Evaluation**          | 가이드라인 정보만으로 실제 양형을 얼마나 설명할 수 있는가?  | 형벌 유형 분류모델 + 기간형 사건의 선고기간 회귀모델 구축           |
| **3. Clustering**                   | 사건 특성에 따라 어떤 잠재적 사건 유형이 존재하는가?     | 선고 이전 사건정보를 이용한 비지도학습 군집화                   |
| **4. Cluster Evaluation**           | 가이드라인의 설명력은 사건 유형별로 어떻게 달라지는가?     | 군집별 분류성능 및 회귀성능 비교                          |
| **5. Error Diagnosis**              | 가이드라인으로 설명되지 않는 오차는 어떤 특성과 관련되는가?  | 오분류 사건과 큰 선고기간 오차 사건의 특성 분석                 |
| **6. Extended Modeling**            | 어떤 추가 정보가 가이드라인의 예측력을 보완하는가?       | 기존 가이드라인 정보 + 추가 피처 모델 구축                   |
| **7. Cluster-specific Improvement** | 추가 피처는 어떤 사건 유형에서 가장 효과적인가?        | 군집별 Baseline과 확장모델의 성능 개선폭 비교               |
| **8. Temporal Validation**          | 추가 피처의 효과가 새로운 사건에서도 유지되는가?        | 과거 연도 학습 후 미래 연도 자료에서 외부검증                  |
| **9. Conclusion**                   | 어떤 정보가 현행 가이드라인의 경험적 예측 한계를 보완하는가? | 분류·회귀·군집·미래연도 검증 결과 종합                      |

# 핵심 비교

본 연구에서는 **Baseline Model과 Extended Model**을 비교한다.

## Baseline Model

현행 연방 양형가이드라인이 제공하는 정보만을 이용한다.

주요 변수:

* `GLMIN`
* `GLMAX`
* `ZONE`
* 기타 가이드라인 자체를 구성하거나 직접 나타내는 정보

Baseline은 다음 두 모델로 구성한다.

### Baseline Classification

실제 형벌 유형을 예측한다.

* 무기징역
* 기간형
* 보호관찰 Only

### Baseline Regression

실제로 기간형이 선고된 사건에서 실제 선고기간을 예측한다.

---

## Extended Model

Baseline 정보에 가이드라인 외의 추가 사건 특성을 결합한다.

핵심적으로 다음을 확인한다.

### 형벌 유형

* Macro F1이 증가하는가?
* 각 형벌 유형의 Recall이 개선되는가?
* 특정 유형 사이의 오분류가 감소하는가?

### 선고기간

* MAE가 감소하는가?
* RMSE가 감소하는가?
* R²가 증가하는가?

### 일반화

* 설명력이 낮았던 군집에서 개선효과가 특히 크게 나타나는가?
* 미래 연도의 새로운 사건에서도 개선효과가 유지되는가?

---

# 연구에서 하지 않는 것

본 연구에서는 `SENTRNGE`를 사용하여 공식적인 가이드라인 내·외 여부를 복원하거나 예측하지 않는다.

실제 선고형량이 단순히 `GLMIN`과 `GLMAX` 사이에 존재하는지를 공식적인 가이드라인 준수 여부로 간주하지 않는다.

또한 보호관찰을 단순히 징역 0개월과 동일한 형벌로 취급하지 않는다. 보호관찰 Only는 별도의 실제 선고유형으로 구분하고, 실제 기간이 존재하는 사건에 대해서만 선고기간 회귀분석을 진행한다.

본 연구의 핵심은 **가이드라인 이탈 여부를 분류하는 것이 아니라, 현행 가이드라인 정보가 실제 형벌의 유형과 기간을 얼마나 설명하고 예측하는지를 평가하는 것**이다.

추가 사건 특성이 예측성능을 개선하더라도 이를 곧바로 해당 변수를 법적 양형가이드라인에 추가해야 한다는 의미로 해석하지 않는다.

본 연구에서 검증하는 것은 다음과 같다.

> **해당 사건정보가 현행 양형가이드라인에 포함된 정보 이상의 추가적인 실제 양형 예측정보를 가지고 있는가?**

따라서 최종 결과는 새로운 법적 양형가이드라인의 제안이 아니라, **현행 가이드라인의 경험적 설명·예측 한계를 진단하고 이를 보완할 가능성이 있는 정보를 탐색한 결과**로 해석한다.
